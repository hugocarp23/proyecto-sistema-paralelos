# Reglas de Comportamiento - Agente IA (SysLab 2.0)

1. **Arquitectura:** Todo el código del backend debe seguir los principios de microservicios / contenedores de SysLab 2.0.
2. **Persistencia:** Las consultas a bases de datos deben realizarse estrictamente a través de Prisma ORM.
3. **Estándar de Commits:** Respetar rigurosamente Conventional Commits en español (`feat`, `fix`, `docs`, `chore`).
